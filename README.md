Senior Design Project | ECE Senior - Eric Simmons | ECE Professor - Valerio Formicola 

GridDyn used in conjunction with Agent LLMs to provide accurate and updated recommendations for Utilities in the event of grid overload or failure. This predictive model will be able to determine failure rate and possible degradation of Utility before disaster strikes. Resource distribution and recommendations will be given to control engineers who can therefore act accordingly to manage any grid where applied.
